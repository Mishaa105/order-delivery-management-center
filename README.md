# ЦЕНТР УПРАВЛЕНИЯ ДОСТАВКОЙ ЗАКАЗОВ

## Описание бизнес-домена

В качестве примера работы системы массового обслуживания рассмотрим работу Центра управления доставкой (ЦУД) заказов Яндекс. ЦУД взаимодействует с сервисами Яндекса (а именно: Яндекс Лавка, Яндекс Еда и Яндекс Маркет) и принимает от них заявки на доставку. Из-за высокой интенсивности входящего потока заказов и ограниченного количества курьеров невозможно обработать все заявки одновременно. Поэтому автоматизированная система ЦУД разделяет поступающие заказы по приоритету сервисов и в периоды пиковой нагрузки при переполнении буфера отклоняет заявки.

### Формула варианта

### Элементы системы:

* **Заявка:** Заказ на доставку, поступающий от сервисов Яндекса. Каждая заявка содержит уникальный ID, время создания и тип источника, на основе которого определяется её приоритет при выборке из буфера и передаче курьеру.
* **Источник (ИБ, ИЗ1):** Сервисы Яндекса (Яндекс Лавка, Яндекс Еда и Яндекс Маркет) направляют заявки на доставку в ЦУД. Поток заявок бесконечный, но распределен по Пуассону. Источники разделены по категориям приоритета.
* **Буфер (Д1ОЗ1):** Взаимодействие сервисов с ЦУД происходит посредством автоматизированной системы управления заказами (АСУЗ). Система обрабатывает заявки и либо отклоняет их, либо отправляет в буфер. Заполнение буфера происходит “по кольцу” (поиск свободного места в буфере осуществляется, начиная с номера места, следующего за последним занятым). Сдвига в очереди не происходит.
* **Прибор (ПЗ2):** Курьеры и роботы-доставщики (равнозначимые сущности) получают заявки. Время на обработку случайное и подчиняется равномерному закону.
* **Дисциплина отказа (Д1ОО1):** При переполнении буфера отказываем заявке, которая находится под указателем, на ее место добавляем пришедшую заявку и передвигаем указатель.
* **Дисциплины постановки на обслуживание:**
  * **Д2Б5 (Выбор заявок пакетами по источнику):** Диспетчер (алгоритм) обрабатывает заявки приоритетного источника одну за другой, когда все заявки данного источника в сформированном пакете будут обработаны, диспетчер переходит к следующему по приоритету источнику.
  * **Д2П1 (Приоритет по номеру прибора):** Выбор прибора происходит последовательным перебором, каждый раз начиная с самого приоритетного. Приоритет определяется номером прибора.
* **Отображение результатов:**
  * **ОР1:** Сводная таблица результатов в автоматическом режиме.
  * **ОД2:** Формализованная схема модели, текущее состояние.
